Set your permanent password

Reset administrator password

Backup required before configuration changes

Download the current complete HBlink4 config before editing or restoring anything.

This backup includes repeater passphrases and other sensitive settings. Store it securely. The editor remains locked until the complete JSON backup has been received by your browser and the download has been triggered.

Talkgroup ACL editor

Each slot can allow all talkgroups, deny all talkgroups, or allow a specific list. Saving changes updates the HBlink4 JSON config but does not alter passphrases or pattern matching rules.

Full configuration backup & restore

Download another complete backup at any time, or restore a previously downloaded HBlink4 config after a rebuild. Restoring replaces the complete config and requires an HBlink4 restart.

Administrator users

Cognito administrators are members of the configured HBlink4 admin group. New users receive an email invitation and set a permanent password on first login.
