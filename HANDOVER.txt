TG9990 parrot timeout/cancellation fix
--------------------------------------
- The previous playback guard treated get_slot_stream(slot) == None as a conflict. Normal HBlink4 hang-time cleanup legitimately removes an ended StreamState, so long echoes could play successfully and then emit Test cancelled once that cleanup occurred.
- hblink4/parrot.py now treats a missing StreamState as a free/safe slot. Cancellation occurs only when an actual conflicting active/reused stream is present or the originating repeater disconnects.
- Regression coverage proves normal stream removal is safe, the original ended stream is safe, an active same stream conflicts, and a different/reused stream conflicts.
- The 120-second parrot recording cap is unchanged; it was not the cause of the observed long-call cancellation.

Voice RF telemetry
------------------
- Optional voice telemetry is independent of the parrot enable flag and is disabled by default in HBlink4 sample configuration.
- Runtime configuration keys under parrot are voice_telemetry_enabled, voice_telemetry_source_id and voice_telemetry_pause_seconds.
- The report speaks average BER, average RSSI and the originating timeslot. Example: "Bit Error Rate zero point four percent. Received Signal Strength Indication minus seventy-two D B M. Timeslot two. Seventy threes."
- Missing RF measurements are spoken as unavailable instead of synthesizing a value.
- If RF becomes active while the optional report is running, HBlink4 stops the report and yields the slot; a successfully completed echo remains successful rather than becoming a parrot cancellation.
- Voice lifecycle events are parrot_telemetry_started, parrot_telemetry_complete and parrot_telemetry_cancelled.

Voice assets and DMR framing
----------------------------
- Production does not require gTTS, ffmpeg, OpenDMR, network TTS access or a runtime vocoder.
- hblink4/parrot_voice_assets.tar.gz contains 210 pre-encoded prompt assets: fixed phrases plus number_0 through number_200.
- scripts/generate_parrot_voice_assets.py is build-time only and uses Australian-English gTTS (lang=en, tld=com.au), 8 kHz signed 16-bit little-endian mono PCM and OpenDMR.
- OpenDMR is pinned to d28164b39ba4d91ad5948ff22707937f8944f70f.
- OpenDMR emits canonical/DVSI AMBE order. hblink4/parrot_voice.py applies the standard DMR 36-dibit AMBE interleave before constructing HomeBrew DMRD voice bursts.
- The interleave regression verifies canonical 49400f09a0e0000000 maps to the standard DMR silence frame acaa40200044408080.
- Generated calls build three Voice Headers, A-F voice bursts at 60-ms cadence and a Voice Terminator with proper Link Control, originating timeslot and originating Colour Code.
- See docs/parrot_voice_telemetry.md for operator/build details and provenance notes.

Known follow-up technical debt
------------------------------
- hblink4/events.py still uses a non-blocking stream socket with sendall; buffered/asynchronous event delivery would be more robust under backpressure, although this has not been demonstrated as a production fault.
- FastAPI on_event startup/shutdown hooks are deprecated and should migrate to lifespan handling when convenient.
- Dashboard version ownership remains split across composed modules and could be centralized later.

Safety notes
------------
- Never expose HomeBrew/OpenBridge passphrases, full configuration backups, password hashes, Cognito tokens/credentials, WebAuthn private material or other secrets in logs, repository content or public APIs.
- Preserve Cognito as primary dashboard authentication and retain the local PBKDF2 administrator as the permanent break-glass path.
- Keep external network TGs and local service TGs explicitly isolated; TG9990 must never become a transit/bridge path.
