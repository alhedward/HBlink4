Current feature: admin voice telemetry toggle
---------------------------------------------
- Goal: make parrot.voice_telemetry_enabled manageable from /admin without a deployment.
- dashboard/parrot_admin.py provides a narrow config projection/editor. It exposes and changes only parrot.voice_telemetry_enabled while preserving all other JSON values.
- The editor reuses TalkgroupConfigStore atomic replacement and backup-on-save behavior, so config/config.json.bak contains the complete pre-change config.
- Writes require the existing authenticated admin session, the existing pre-edit full-config backup gate, a matching config revision, and CSRF protection.
- The control is available to both Cognito administrators and the permanent local PBKDF2 break-glass administrator.
- dashboard/static/admin_parrot_voice.js injects a dedicated Parrot voice telemetry card with an On/Off switch and Apply & restart HBlink4 action.
- Applying the switch changes the live config through the narrow endpoint and then calls the existing fixed-command /api/admin/restart path, which verifies hblink4.service returns active.
- The parrot echo enable flag is independent and is not changed by this control.
- Dashboard release/cache-buster on this feature is 1.3.3 / 20260830-parrot-admin-1.

TG9990 parrot behaviour already in main
----------------------------------------
- Long echoes no longer false-cancel when ordinary stream-state hang-time cleanup releases the originating slot. Missing StreamState means free/safe; cancellation requires an actual active/reused conflict or repeater disconnect.
