Admin authentication
--------------------
- Existing HBlink4 /admin page remains the administrator entry point.
- Existing local HttpOnly session cookie, CSRF protection, login throttling, mandatory full-config backup gate, config restore protection and fixed restart authorization remain in place.
- auth_provider=local uses the existing PBKDF2 administrator credential.
- auth_provider=cognito uses an Amazon Cognito User Pool behind the same HBlink4 login UI.
- Cognito administrators must belong to the configurable HBlink4Admins group.
- Cognito mode provides named users, emailed invitations, temporary-password first login, self-service password reset, admin listing, invite resend and administrator-triggered password reset.
- Cognito first-login Session values remain server-side; the browser receives only an opaque short-lived challenge token.
- Optional Cognito app-client secret support exists, but production intentionally uses no client secret; EC2 IAM authorizes the server-side admin authentication operations.

Current feature: permanent local break-glass login
--------------------------------------------------
- feat/cognito-local-breakglass adds an ASGI authentication wrapper used by run_dashboard.py.
- When auth_provider=cognito, the exact configured legacy local username is reserved as the PBKDF2 break-glass account.
- That reserved username is authenticated locally and is never sent to Cognito.
- A wrong password for the reserved local username fails locally and is never retried against Cognito.
- Every other username is replayed unchanged to the normal HBlink4 Cognito login route.
- The break-glass account therefore remains usable during a Cognito service outage as long as the deployed Cognito configuration itself remains present.
- The deployment repository already preserves the local PBKDF2 hash in its root-only environment/SSM path when Cognito is selected.
- Production must remain auth_provider=local until this change passes the full regression workflow, is merged, pinned by hblink-website and deployed.
